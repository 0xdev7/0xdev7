<br/>

`Next.js 14` `TypeScript` `ethers` `wagmi v2` `Reown AppKit` `Sumsub` `Apollo`

<details>
<summary><b>🔁 Intent-based settlement: UniswapX, 1inch Fusion, CoW & OKX</b> · <i>2026</i></summary>
